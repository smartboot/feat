Feat AI 适合已经会写 Java 服务，现在想把模型能力接进来的开发者。

## 编写第一个应用

你将构建一个最小的 AI 对话应用，让模型返回一段关于 Feat 框架的介绍文本。

**前置要求**：JDK 8+、Maven 3.6+、以下二选一：
- **本地 Ollama**：已安装并运行，且本地拉取了可用模型
- **云端模型**：已准备好环境变量 `FEAT_AI_API_KEY`

### 1. 添加依赖

在 `pom.xml` 中加入：

```xml title="pom.xml"
<dependency>
    <groupId>tech.smartboot.feat</groupId>
    <artifactId>feat-ai</artifactId>
    <version>${feat.version}</version>
</dependency>
```

<Aside>
`${feat.version}` 请替换为实际版本。最新版本可以在 [Maven Central](https://central.sonatype.com/artifact/tech.smartboot.feat/feat-ai) 查看。
</Aside>

### 2. 编写程序

<Tabs>
    <TabItem value="本地 Ollama" label="本地 Ollama（最快验证）">

先确认本地模型可用：

```shell
ollama run qwen2.5:7b
```

然后创建 `HelloFeatAI.java`：

```java title="HelloFeatAI.java"
import tech.smartboot.feat.ai.FeatAI;
import tech.smartboot.feat.ai.chat.ChatModel;

public class HelloFeatAI {
    public static void main(String[] args) throws Exception {
        ChatModel model = FeatAI.chatModel(opts -> opts
                .baseUrl("http://localhost:11434/v1")
                .model("qwen2.5:7b")
        );

        System.out.println(model.chat("用一句话介绍 Feat 框架").get().getContent());
    }
}
```

<Aside type="tip">
本地 Ollama 直接访问本机服务，不需要配置 `FEAT_AI_API_KEY`。
</Aside>

    </TabItem>
    <TabItem value="云端模型" label="云端模型">

Feat AI 默认使用 Gitee AI 的 OpenAI 兼容接口。将 API Key 配置到环境变量后，可以直接使用默认服务地址：

```shell
export FEAT_AI_API_KEY=你的_API_Key
```

```java title="HelloFeatAICloud.java"
import tech.smartboot.feat.ai.FeatAI;
import tech.smartboot.feat.ai.chat.ChatModel;

public class HelloFeatAICloud {
    public static void main(String[] args) throws Exception {
        ChatModel model = FeatAI.chatModel(opts ->
                opts.model("Qwen2.5-72B-Instruct")
        );

        System.out.println(model.chat("用一句话介绍 Feat 框架").get().getContent());
    }
}
```

如果使用其他 OpenAI 兼容服务，再通过 `baseUrl(...)` 指定服务地址。

    </TabItem>
</Tabs>

### 3. 运行并验证

运行 `HelloFeatAI.main()`，控制台应该出现一段真实文本，类似：

```text
Feat 是一个轻量级、高性能的 Java Web 服务开发框架。
```

只要满足以下三点，就算成功：

- 没有抛异常
- 控制台有输出
- 不是空字符串

<Aside type="tip">
这里使用 `chat(...).get()`，是为了让命令行程序等待模型返回完整结果。真实服务端代码通常应组合 `CompletableFuture`，避免在请求处理线程中阻塞。流式调用的版本差异和用法见[对话模型](/feat/ai/chat/)。
</Aside>

## 两种调用方式的区别

Feat AI 提供两种与模型交互的方式，选择取决于你的场景：

| 方法 | 返回值 | 适用场景 |
|------|--------|----------|
| `chat(...)` | `CompletableFuture<ChatResponse>`| 需要完整结果后再处理，如后端任务、数据提取 |
| `chatStream(...)` | `void`（通过 `ChatStreamListener` 回调；v2.5.0 起返回 `CompletableFuture<ChatResponse>`） | 需要实时消费片段，如终端输出、前端打字机效果 |

## 常见问题

### 本地 Ollama 没有输出

1. 确认 Ollama 服务正在运行
2. 确认本地已拉取对应模型（`ollama list`）
3. 确认 `baseUrl` 与本机环境一致（默认端口 11434）

### 云端模型报错

优先检查 `FEAT_AI_API_KEY` 是否在当前运行环境中可见，而不是只在另一个终端窗口 `export` 过。
