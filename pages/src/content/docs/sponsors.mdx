Feat Core 与 Feat AI 采用 Apache 2.0 开源协议，开发者和企业可以按协议使用、修改和分发。

Feat Cloud 面向企业采用赞助支持模式。企业完成赞助后，可解锁 Feat Cloud AOT 编译 License。赞助不仅是对项目持续维护、性能优化、文档完善和生态建设的支持，也是企业获得 Feat Cloud 相应 License 的方式。

本页展示赞助者名单，并提供 Feat Cloud AOT 编译 License 生成入口。感谢每一家支持 Feat 的企业与个人。
