Feat 全部模块均采用 Apache 2.0 开源协议。企业和开发者可以按照协议使用、修改和分发 Feat，使用 Feat Cloud 不需要以赞助或申请额外授权为前提。

我们欢迎正在使用 Feat 的企业通过赞助支持项目。赞助将帮助项目持续维护、改进性能、完善文档与示例，并推动新功能和生态建设。这是对开源项目长期发展的支持，而不是购买软件使用资格。

这一页公开展示赞助者名单，并向所有支持 Feat 的个人与企业致谢。
