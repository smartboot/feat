Feat Core、Feat AI 与 Feat Cloud 均采用 Apache 2.0 开源协议。开发者和企业可以按协议使用、修改和分发，使用 Feat Cloud 及其 AOT 编译能力不以赞助为前提。

赞助是对项目持续维护、性能优化、文档完善和生态建设的自愿支持。赞助企业可以使用本页的 Feat Cloud AOT License 生成入口，生成可选的构建期 License 配置。根据当前实现，不配置 License 时，注解处理器不会因缺少 License 而阻止正常生成；只有显式配置 License 时才会执行签名和组织信息校验。

本页展示赞助者名单，并提供可选的 Feat Cloud AOT License 生成入口。感谢每一家支持 Feat 的企业与个人。
